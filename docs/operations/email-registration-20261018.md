# 注册改回邮箱（2026-10-18）

按项目方最新要求，公开注册只使用邮箱。这条要求取代 T06 规格里“手机号自注册”的部分；T06 的游客初始角色、入班权限和权限变更后的会话处理继续保留。

## 改动

- 独立登录页和学习页弹窗都使用邮箱验证码注册。验证码有效期为 300 秒，重发冷却为 60 秒，页面读取接口返回的时间。
- `/api/v1/auth/register` 只接受邮箱、邮箱验证码、密码、昵称和图片验证码；手机号、短信验证码或其他额外字段返回 422。
- `/api/v1/auth/sms/send` 返回 410 和 `sms_registration_disabled`，提醒旧客户端改用邮箱；不发送短信、不读取或消耗验证码。
- 邮件服务明确返回发送失败时，接口返回 502、`application/problem+json` 和 `email_gateway_failed`。保留失败审计及已消费的图片验证码，不保存可用邮箱验证码；前端显示中文错误。
- 注册成功后保持游客角色，并返回登录表单，不自动建立会话。邮箱、已有用户名和学号仍走原登录接口。

## 数据和发布

不增加迁移，不删除手机号字段、旧账号或短信历史。保留旧身份的内部服务和登录兼容性。已有聊天、角色、价格和额度不需要调整。

先将 PR 合并到 develop，部署到 `test.lsnunlp.com`。在测试站复验邮箱收信、注册、登录、对话、额度百分比和双标签页同步后，再安排正式站发布。合并本 PR 不代表正式站已更新。

## 仍需继续查的事

这次修正注册方式和邮件失败响应，不能保证外部邮件始终及时到达。之前 QQ 邮箱延迟十多分钟的事件仍需要腾讯云投递记录；服务商接收成功不等于已经进收件箱。

沙箱事件路由、模型上游失败和课堂并发容量等问题需要各自继续处理，不能用这次注册测试代替验收。
