## Nova v2.0.0

Nova 是一个面向自然语言处理教育与学习的 AI 平台，支持智能对话、知识学习、练习反馈、教师内容管理和运行监控。

### 核心能力

- **学生工作台：** AI 对话、知识教材、代码沙箱和学习上下文
- **教师工作台：** 知识内容编辑、发布和教学内容管理
- **开发者 / 监控工作台：** 运行链路、模型调用、Token 与缓存指标，以及系统可观测性
- **身份验证与工作台：** 登录状态管理、会话过期处理和基于角色的工作台
- **Docker 部署：** 支持 FastAPI、React、MySQL、Redis、WebSocket 和实时运行能力

### 快速体验

- **在线演示：** [https://lsnunlp.com](https://lsnunlp.com)
- **本地部署：** 请参阅 README 中的 Docker Compose 启动说明
- **演示流程：** 通过演示课程体验知识教材和代码沙箱功能

### 版本亮点

- 改进学生、教师和开发者工作台
- 增强知识教材与代码沙箱之间的联动体验
- 完善模型用量统计、缓存命中率测量和运行监控
- 改进登录会话处理和前端会话过期状态
- 增加回归测试、部署文档和可观测性支持

### 验证结果

- 前端单元测试通过
- ESLint 检查通过
- TypeScript 类型检查通过
- 生产环境构建通过
- 本地 Docker Compose 环境验证通过

### 已知限制

- 部分模型和沙箱功能依赖本地或生产环境中的 Provider 配置及运行时设置
- 由于环境配置不同，在线演示和本地部署所支持的功能可能存在差异
