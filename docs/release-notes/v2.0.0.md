# Nova v2.0.0

Nova v2.0.0 正式发布——一次部署即可让教师、学生、开发者和运维四类角色在同一套实例上协同工作，为 NLP 课堂提供从备课、答疑、练习到批改与观测的完整闭环。

## 新增功能 (What's New)

- **四角色一体化工作台**：学习者、教师、开发者、运行监控四个视图由访问控制严格隔离，一套部署即覆盖整个班级，无需为不同人群搭建多套系统。
- **引导式教学对话**：学生用自然语言提问，得到的是逐步拆解的讲解而非一次性的最终答案，把推理过程完整还给学生。
- **蓝图驱动的自动出题与加权批改**：教师一次性定义练习蓝图，系统自动生成题目，并对照教师设定的加权评分细则给每份作答打分，保证全班批改口径一致。
- **知识点目录与精确注入**：教师用 Markdown 编写主题与知识点，每次提问只注入题目真正需要的范围，避免无关上下文干扰模型回答。
- **全链路可观测面板**：内置运行监控视图，可实时查看 web、worker 与 sandbox 的轮次、追踪与指标，从客户端提问一路追踪到最终答案。
- **网页与命令行双端**：浏览器和终端均可对话，师生不受单一界面束缚。

## 部署环境 (Deployment)

本地运行需满足以下基础环境：

- **Python 3.11 或更高版本**，以及 [uv](https://docs.astral.sh/uv/) 包管理器。
- **MySQL 8.4**（数据持久化）与 **Redis 7.4**（任务队列 / 网关传输）。
- **Node.js >= 22 且 < 25**（构建 `webui` 前端）。
- **Docker 及 Docker Compose**（完整分布式栈与隔离代码执行沙箱）。
- **一个模型服务的 API Key**：支持 DeepSeek、OpenAI、通义千问、Moonshot、智谱 GLM 等兼容服务，密钥配置在 `.env` 中。

完整分布式部署示例见仓库根目录 [`compose.yaml`](./compose.yaml)。

## 已知限制 (Known Limitations)

- **依赖外部模型服务**：对话与批改能力依赖第三方模型 API Key，无法在完全离线或网络受限的环境中运行。
- **沙箱依赖 Docker**：隔离代码执行与作业运行需要 Docker 运行时及相应宿主机资源配置。
- **大规模并发尚未充分验证**：当前版本在中小规模班级场景下表现稳定，横向扩展与超大规模高并发下的吞吐能力仍需更多生产级压测验证。

## 快速体验 (Quick Start)

只需三步，本地即可跑起完整实例：

**第一步：获取代码并准备配置**

```bash
git clone https://github.com/liunor/nlp-agent.git
cd nlp-agent
cp .env-example .env   # 填入模型服务密钥与数据库连接
uv sync                # 安装依赖
```

**第二步：初始化数据库与首个账号**

```bash
uv run python main.py bootstrap-db
uv run python main.py bootstrap-developer
```

**第三步：启动并访问**

```bash
uv run python main.py serve
```

启动成功后，在浏览器打开 <http://127.0.0.1:8765> 登录即可。需要完整分布式栈时，使用 `docker compose up -d` 一键拉起 nginx、MySQL、Redis、web、worker 与 sandbox manager。
